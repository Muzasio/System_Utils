# System Utilities & Automations

###  ProRes 4444 Converter (FFmpeg + Nautilus)
Drag-and-drop converter for videos or PNG folders to **ProRes 4444 MOV** for Resolve.  
Auto-renames, preserves alpha, and safely organizes exports.

### DNxHR & ProRes Converter (Batch Script)
Batch-convert videos or PNG sequences to **DNxHR LB** or **ProRes 4444**.  
Handles renaming, logging, and skip-on-duplicate automation.

### MOV → DNxHR Converter
Quickly turns `.mov` files into lightweight **DNxHR LB** for editing.  
Non-destructive, progress-tracked, and Nautilus-ready.

###  PNG → ProRes 4444 (Zenity GUI)
GUI-based converter for numbered PNGs to **ProRes 4444 MOV**.  
Simple, fast, and alpha-channel-safe for animation workflows.

### Enterprise YouTube Downloader
Root-free YouTube downloader using **yt-dlp + ffmpeg** with retry & logs.  
Downloads MP4 or MP3 cleanly to organized user folders.
